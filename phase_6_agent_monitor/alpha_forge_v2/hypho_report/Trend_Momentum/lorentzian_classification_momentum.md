## Core Hypothesis — WHY should this strategy have an edge?
Traditional machine learning and distance metrics in crypto often fail because standard Euclidean distance is highly sensitive to extreme volatility spikes and "fat-tail" events. By utilizing the non-Euclidean **Lorentzian distance** metric ($\sum \ln(1 + |x_i - y_i|)$) to compare the current market state (defined by momentum features like RSI, CCI, and ADX) against a rolling history, we can robustly filter out these noisy outliers. This enables a K-Nearest Neighbors (KNN) classifier to accurately identify true repeating fractal patterns in price action. Applying a regime filter of ADX > 20 and aligning with the macro trend via EMA(200) ensures the model only seeks patterns during environments with sufficient structural momentum, preventing false positive classifications during low-volatility chop.
