**Key Logic:**
```python
# TII calculation in library.py
def calc_trend_intensity_index(close, major_period=60, minor_period=30):
    sma = close.rolling(major_period).mean()
    pos_dev = (close - sma).clip(lower=0)
    neg_dev = (sma - close).clip(lower=0)
    pos_sum = pos_dev.rolling(minor_period).sum()
    neg_sum = neg_dev.rolling(minor_period).sum()
    total = pos_sum + neg_sum
    return (pos_sum / total * 100).where(total > 0, 50)
```
