Theoretical Execution Logic: Cross Up
Prior to the signal, Asset B was outperforming Asset A, driving the spread negative. As the assets begin to mean-revert, the spread narrows. The exact moment the spread hits zero (Bar 50), the algorithm determines that momentum has shifted to Asset A.
↗ LEG 1: LONG ASSET A
Expecting Asset A to continue climbing.
↘ LEG 2: SHORT ASSET B
Expecting Asset B to continue falling.
ANTI-CORRELATION CROSSOVER — MOMENTUM ROTATION
Concept: "The Changing of the Guard"
Unlike Phase 10 which relies on long-term gravity (mean reversion), Phase 11 relies on momentum shifts. It watches two diverging assets. It waits for the exact moment the underdog steals the momentum (the spread crosses zero). You bet that the trend has broken and capital is rotating from the winner into the loser.
Trades the zero-crossing of relative performance between two assets. When the faster asset has led and the spread crosses zero, momentum is expected to rotate to the lagging asset — we go long the lagging, short the leading right at the intersection point.
Example Scenario: SOL & ADA
  1. The Divergence: Over 48 hours, SOL is up 15% and ADA is down 5%. SOL is the undisputed leader.
  2. The Shift: Market sentiment shifts. SOL drops to +2% while ADA climbs to +2%.
  3. The Zero Cross: At the exact moment they both hit +2%, the Spread hits exactly 0. ADA's momentum has officially overtaken SOL's momentum.
  4. The Execution: We LONG ADA (the new leader) and SHORT SOL (the dying leader). We hold until ADA out-gains SOL by our target amount.
① RELATIVE PERFORMANCE SPREAD (NORM_WINDOW = 48h)
S[i] = (P_A[i] / P_A[i−N] − 1) − (P_B[i] / P_B[i−N] − 1) S > 0 → A has outperformed B over the lookback window S < 0 → B has outperformed A over the lookback window N = NORM_WINDOW bars
② PRIOR DIVERGENCE GUARD (PRIOR_DIV_WINDOW = 24h)
prior_peak = max(|S[i−PRIOR_DIV_WINDOW : i]|) Entry only fires if prior_peak ≥ MIN_DIVERGENCE (0.08) Ensures a meaningful divergence existed BEFORE the crossover — not a noise signal hovering near zero.
③ ZERO-CROSSING ENTRY SIGNAL
cross_up = S[i−1] < 0 AND S[i] >= 0 (B led, now A catches up) cross_down = S[i−1] > 0 AND S[i] <= 0 (A led, now B catches up) Signal fires the exact bar the spread changes sign.
④ DIRECTION LOGIC
cross_up (S: − → +): A was lagging, now catching up → Long A / Short B cross_down (S: + → −): B was lagging, now catching up → Short A / Long B
⑤ ENTRY GATES (ALL must be true)
1. cross_up OR cross_down — spread crossed zero this bar
2. prior_peak ≥ MIN_DIVERGENCE — prior divergence ≥ 0.08
3. MIN_PEAK_BARS (4) — divergence persisted ≥ 4 consecutive bars above threshold
4. No open position on this pair
⑥ POSITION SIZING
capital_per_leg = CAPITAL × RISK_FRACTION / 2 size_A = capital_per_leg / P_A[entry] (equal-dollar legs) size_B = capital_per_leg / P_B[entry] fee = 4 × capital_per_leg × TRADING_FEE (2 legs × open + close)
⑦ IN-TRADE SPREAD — S_trade
ret_A = P_A[i] / P_A[entry] − 1 ret_B = P_B[i] / P_B[entry] − 1 S_trade = ret_A − ret_B (relative outperformance of A over B since entry) Long A / Short B direction: profit when S_trade > 0 Short A / Long B direction: profit when S_trade < 0
⑧ EXIT CONDITIONS (checked every bar)
1. PROFIT — |S_trade| ≥ PROFIT_TARGET (10%) in the winning direction
2. RECROSS — S[i] crosses zero against the trade direction with buffer: |S[i]| ≥ RECROSS_BUFFER (3%) before triggering
3. HARD_STOP — |S_trade| ≥ HARD_STOP_PCT (15%) in the losing direction
4. TIME_STOP — bars_held ≥ MAX_HOLD_BARS (24h × bars_per_hour)
⑨ P&L CALCULATION
Long leg: pnl_x = size_x × (exit_px − entry_px) Short leg: pnl_x = size_x × (entry_px − exit_px) gross_pnl = pnl_A + pnl_B net_pnl = gross_pnl − fee ROI = net_pnl / (2 × capital_per_leg)
⑩ ROLLING PEARSON CORRELATION (visualised in Correlation tab)
ret_a[i] = log(P_A[i] / P_A[i−1]) ret_b[i] = log(P_B[i] / P_B[i−1]) ρ[i] = Pearson( ret_a[i−W : i], ret_b[i−W : i] ) W = CORR_WINDOW bars Pair selection targets ρ < −0.3 (negative correlation confirms assets move in opposite directions — prerequisite for rotation signal).
⑪ KEY PARAMETERS
Parameter Value Description
NORM_WINDOW 48h Lookback for S[i] spread
PRIOR_DIV_WINDOW 24h Lookback for prior divergence check
MIN_DIVERGENCE 0.08 Min prior_peak to allow entry
MIN_PEAK_BARS 4 Divergence must persist ≥ N bars
PROFIT_TARGET 10% S_trade threshold for profit exit
RECROSS_BUFFER 3% Buffer before recross exit triggers
HARD_STOP_PCT 15% Max adverse S_trade before hard stop
MAX_HOLD_BARS 24h Maximum trade duration
